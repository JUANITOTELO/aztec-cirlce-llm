## Atomic Architecture Rules (STRICTLY ENFORCED)
1. **File Size Limit**:
   - No single source file (*.ts, *.tsx) may exceed **150 lines**.
   - Split large components into smaller atomic primitives and custom hooks.

2. **Atomic Directory Structure (MANDATORY)**:
   - `src/atoms/`: Single-purpose UI primitives (e.g. Button, Slider, Badge, Toggle, ColorSwatch) — max 60 lines each.
   - `src/components/`: Composite UI panels (e.g. Toolbar, Inspector, PresetGrid, HelpModal) — max 120 lines each.
   - `src/hooks/`: React custom hooks only (e.g. usePoseHistory, useCameraControl, useTheme) — max 80 lines each.
   - `src/engine/`: Pure domain logic, 3D math, kinematics, simulation (no React/JSX imports) — max 150 lines each.
   - `src/store/`: State management slices (e.g. mannequinStore, uiStore) — max 100 lines each.
   - `src/utils/`: Pure utility functions with zero side effects — max 80 lines each.
   - `src/types/`: TypeScript interfaces and types only — max 100 lines each.
   - `src/constants/`: Configuration and fixed preset data — max 100 lines each.

3. **Single Responsibility Principle**:
   - Component files contain ONLY direct JSX and UI bindings.
   - Business calculations, math, side effects, and state logic MUST be extracted to `src/hooks/` or `src/engine/`.
   - NEVER create monolithic "God files" that combine domain models, UI state, and constants.

4. **Import Discipline**:
   - `src/engine/` and `src/utils/` files MUST NOT import from React or UI components.
   - `src/atoms/` files MUST NOT depend on `src/store/` or `src/engine/`.
